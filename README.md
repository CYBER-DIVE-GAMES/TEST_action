# JRA 中央競馬 予想ツール

netkeibaスクレイピング × LightGBM × 期待値理論による  
複勝・ワイド・馬連・3連複の推奨馬券生成ツール

---

## セットアップ

```bash
pip install -r requirements.txt
```

---

## 使い方

### 1. 過去データ収集（初回のみ・数時間〜数日かかります）

```bash
python main.py collect --start 2019 --end 2024
```

- netkeibaから全レース結果・オッズ・馬プロフィールを収集
- `data/jra.db`（SQLite）に保存
- サーバー負荷軽減のためリクエスト間隔2秒を設定済み

### 2. モデル学習

```bash
# 通常学習
python main.py train

# ハイパーパラメータ自動チューニング付き（時間がかかる）
python main.py train --tune
```

### 3. バックテスト

```bash
python main.py backtest --years 2 --budget 10000
```

直近2年をテスト期間として、それ以前のデータで学習した結果を検証。

### 4. 直近レース予測

```bash
python main.py predict 202406010501 202406010502 --budget 10000
```

レースIDは12桁：`YYYYMMDDCCRR`
- YYYY: 年
- MM: 月
- DD: 日
- CC: 競馬場コード（05=東京、06=中山、など）
- RR: レース番号

## 特徴量一覧

| カテゴリ | 内容 |
|---|---|
| 近走成績 | 直近3/5/10走の勝率・複勝率・平均人気 |
| 騎手能力 | 直近30/100戦の勝率・コース別・距離別 |
| 調教師 | 直近50戦の勝率・複勝率 |
| コース適性 | 馬×競馬場、馬×距離帯、馬×馬場状態の実績 |
| ペース | 脚質（先行/差し/追込）、展開予測 |
| 血統 | 父別・父×距離帯の勝率 |
| 馬体重 | 体重トレンド、斤量ハンデ |
| オッズ | 市場評価との乖離（期待値の核心） |

## 注意事項

- netkeibaのスクレイピングは利用規約を確認の上、適切な間隔を守ってください
- 回収率は過去データのバックテスト結果であり、将来の利益を保証するものではありません
- 競馬は控除率（約25%）があるため、長期的な回収率100%超の維持には継続的なモデル改善が必要です
